# Train Delay Propagation Project — Report Outline

## 1. Title
Data-Driven Simulation of Train Delay Propagation Using Route Distance and Historical Station Delay Patterns

## 2. Objective
Study how an initial delay is carried forward or attenuated across a route while representing additional disruptions using historical station delay patterns.

## 3. Dataset
Historical station delay information is available for 42 train routes. The distance-based simulation uses the 23 trains matched to the external cumulative-distance dataset. Station records without matched distances are excluded from the simulation master dataset.

## 4. Methodology
1. Match train numbers across the historical train list and distance dataset.
2. Match station codes and cumulative distance.
3. Sort each route by cumulative distance and calculate distance between consecutive stations.
4. Apply 100%, 90%, 80%, or 70% carry-forward rates using the defined distance thresholds.
5. Sample historical station condition using supplied percentages.
6. If the sampled condition worsens and historical average delay increases, add the positive difference as a modeled new disruption.
7. Track initial and new-disruption components separately.
8. Compare initial delays of 30, 60, and 120 minutes.

## 5. Assumptions and limitations
Carry-forward rates and the disruption-generation rule are simulation assumptions. Random sampling is seeded by train number for reproducibility. The project should be described as a simulation rather than a validated predictive model because independent observed final-delay outcomes are not available.
